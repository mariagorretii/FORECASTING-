# ✈️ Airline Passengers Forecasting Using SARIMA

## Overview

Proyek ini bertujuan untuk membangun model peramalan jumlah penumpang maskapai penerbangan menggunakan metode SARIMA (Seasonal Autoregressive Integrated Moving Average). Model dibangun menggunakan data pelatihan (train set) dan dievaluasi menggunakan data pengujian (test set) untuk mengukur kemampuan prediksi terhadap data yang tidak digunakan selama proses pelatihan. Hasil evaluasi menunjukkan nilai MAPE sebesar 3,03%, yang mengindikasikan bahwa model memiliki tingkat akurasi yang sangat baik dalam menangkap pola tren dan musiman pada data.

## Tools
- R
- forecast
- ggplot2

## Key Result
- MAPE: 3,03%
- RMSE: 19,53
- MAE: 12,83
